# Admin panel (/admin/*)

Scope: every signed-in admin screen plus the login. Mode: Operate. The owner manages albums (projects), event galleries with watermarks, quotes (orçamentos) with PDF export, and Instagram client accounts, on a Mac and on a phone. Redesign only: every function, state, handler, data call, route and piece of copy meaning stays.

## Direction contract

THESIS: a quiet, consistent photo-studio workbench. One frame (sidebar with Projetos, Eventos, Orçamentos, Instagram; Ver site, Página de links, Sair), one component vocabulary on every screen; it refuses the old per-page headers, 9px tracked caps and 30%-white text.

OWN-WORLD: neutral graphite workspace (#141516 canvas, #1C1D1F panels, #0F1011 sidebar), chrome-light primary actions (#E9EAEC on #141414 text, the booth button's chrome), status colours only for status (success #3BBE7A, warning #E0A33B, danger #EE4B43, info #5B9BE6). One family, Archivo, fixed scale 12/13/14/15/17/20/24px; the GoFocus wordmark in Big Shoulders is the only brand display type.

STORY: the owner opens a screen, sees what is there and its state at a glance, and finishes the task in the fewest steps.

FIRST VIEWPORT: sidebar left (menu sheet on phones); page title at 24px with a one-line description and the primary action on the right; content in panels or tables below.

FORM: shared admin frame (Operate); seed: none (unavailable).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
